# v1.7.0 — Accept all, numbers filter, two-file import and safer DOCX handling

- **Review workflow.** "Accept all open" accepts every open change in the comparison after a confirmation that names the count and scope (including filtered entries and every page of grouped headers and footers), and it is one undo step. A new "Numbers, currencies & percentages" filter isolates changes to digits, amounts and percentages, and once everything is reviewed the action offers the final Word export. Review tooltips explain accepting, restoring and undoing, and the stepper and floating review controls support the reading shortcuts.
- **Import.** Both file pickers accept two files at once: the first is the old version, the second the new one. Replacing a reviewed pair asks once instead of twice, an explicit load starts a clean baseline, and cancelling the prompt lets you pick the same file again. A swap button in the top bar exchanges the two versions.
- **Safer DOCX and PDF handling.** DOCX archives are read with fixed limits (4,096 parts, 64 MiB per part, 256 MiB in total) before import and source export. Original-format Word export refuses ambiguous table edits and offers a newly typeset document (`_Generated.docx`) instead. PDF pages and loading tasks are cleaned up after extraction.
- **Fixes.** Rejected header/footer changes keep their numeric differences and still stay grouped across pages; the `hidden` attribute always hides elements; dark-mode links use the readable ink colour; narrower laptop widths get tighter padding; the English pages ship an English web app manifest.
